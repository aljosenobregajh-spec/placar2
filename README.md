# Placar · simulador de futebol

Site pessoal para simular ligas, copas e partidas com regulamentos oficiais.

- No computador: abra o `index.html` com dois cliques.
- No celular: acesse o endereço do GitHub Pages e use "Adicionar à tela inicial" no Chrome.

## Atualizar o site publicado

1. Troque ou adicione os arquivos nesta pasta.
2. Abra o GitHub Desktop: as mudanças aparecem na lista da esquerda.
3. Escreva um resumo no campo "Summary" e clique em **Commit to main**.
4. Clique em **Push origin**. Em 1 ou 2 minutos o site e o app no celular estão atualizados.

Os dados (competições salvas, clubes editados) ficam no navegador de cada aparelho
e não vão para o GitHub.
